# WebSocket生命周期与请求关联修复

日期：2026-10-18。参考上游[PR #410](https://github.com/w1249178256/xyzw_web_helper/pull/410)，只适配用户确认的第3项通信稳定性修复。

## 范围

主游戏连接src/utils/xyzwWebSocket.js、盐场连接src/utils/xyzwLegionWarWebSocket.js、后端连接render-backend/lib/gameClient.js，以及tokenStore关闭连接时的等待与定时器回收。保留本项目新增命令、响应映射、主连接多订阅、当前账号隔离和服务器时钟API；没有引入上游挂机加钟、分享参数、任务互斥、任务调度或EdgeOne功能。原30%失败补跑和推送规则保持原实现。

## 改动与效果

- 请求超时立即删除等待项及对应未发送队列项；断开清空旧队列、请求和延迟心跳、重连等定时器。已经发送的请求无法撤回，本修改不代表超时请求一定没有在服务器执行；任务仍需按既有状态复查处理。
- 队列号与实际发送号区分：编码成功、实际发送前关联请求到连续的线上seq，发送成功后推进线上编号；未发送即取消或编码/同步发送失败不消耗线上编号。
- 数字resp（含数字字符串与0）只关联对应请求，找不到则忽略，不能按命令名误完成后来同名请求。无数字编号的兼容响应继续使用项目现有映射；它本身没有请求编号，仍无法保证区分所有同名迟到响应。
- 每个连接事件及延迟Blob解码绑定当时socket，旧open/message/close/error和延迟定时器不能作用于替换后的连接。主连接原有订阅入口保持，且新连接重新开始服务器时钟和线上编号。
- 后端连接建立超时和断开时释放建立连接的Promise及等待项，同步编码/发送异常即时释放，不等待超时才失败。
- tokenStore保留已有isCurrentClient回调保护；优雅关闭保存原socket，等待它真正关闭或达到5秒上限，并回收轮询定时器，避免仅以connected=false当作原生连接已经关闭。原连接被替换时不删除新连接记录或释放新锁。
