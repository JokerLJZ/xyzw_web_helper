# 十殿星级挑战一次

## 使用

副本与挑战板块新增“一键星级挑战一次”，对选中账号逐个执行。手动按钮不限星期。日常设置与批量模板新增“周一星级挑战一次（保存阵容）”，新旧账号默认关闭；开启后仅北京时间周一执行，定时日常共用该选项。独立按钮也登记在副本类任务目录及定时白名单。

先确认本周十殿通关达到开放门槛，星级数据已经刷新至本周；逐层检查剩余次数。仅使用游戏内该层保存阵容，缺少阵容跳过。每层本轮最多请求一次，不论获得几星均不追加挑战。即使已满星，只要仍有次数也按用户要求挑战一次。没有次数的层跳过。保存阵容未带玩具、宠物时保留空配置，不套用主阵容，也不修改主阵容。只发战斗请求，不购买次数、不抽罗盘、不自动领取星级奖励。

## 异常与边界

所有账号分别查询角色、星级与阵容。每次战斗后重新查询星级次数；响应超时但次数已增时记为已执行，不重发；次数未确认则停止后续层。不用请求成功或本地战斗结果推测胜利。跨周、自动执行跨出周一、用户停止均停止后续请求。现有连接队列、账号任务会话及请求间隔继续生效。

没有查询真实账号或发起真实挑战；当前响应模型来自官方协议。实际服务端返回以及本周已通关资格的表现仍需用户试用。后续游戏更新需重新取manifest，复查上述UI、资格、特权配置、按层保存阵容、协议注册和响应模型，不直接复用本文hash。
