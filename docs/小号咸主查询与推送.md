# 小号咸主查询与 WxPusher 推送

## 使用方式

在批量任务页面选择账号，进入“小号任务”，点击“查询咸主并推送”。需要在批量任务设置中启用 WxPusher，并填写 AppToken 和 UID。

逐账号查询当前是否有咸主，命中时发送一份账号名称、区服、咸主角色ID清单；未命中不发送。查询失败单独记日志，不作为自由账号，也不进入命中清单。部分失败时仍可推送成功命中项，报告同时说明失败数量。配置未启用或不完整、推送失败均明确记录日志。

该任务也可在定时任务中选择。定时按账号采集，结束后统一发送，跳过通用 WxPusher 完成通知，避免无命中仍发消息。查询任务单独运行时只初始化角色信息；与其他任务一起执行时，其他任务仍使用原有初始化与操作流程。

停止后不启动下一账号；已完成查询的命中项可形成部分清单，未执行账号不在报告中。不会自动反叛、征服、放逐或发送游戏写指令。
