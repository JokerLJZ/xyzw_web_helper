## 修复

请求编号保持主动 -1、被动 0/1/2。计划和最终复查共用 isHeroAwakeSlot，主动改为读取 isActive，被动仍读取 awakeSkill。避免已觉醒主动技能重复发请求，也修复新觉醒成功后复查统计错误。未将 400200 直接视为成功；服务器错误仍保留失败处理，避免掩盖状态不一致。

回归覆盖 isActive=true 且 awakeSkill 缺失、主动与被动字段独立、编号与 Map 兼容、新觉醒后的复查以及已觉醒账号零指令完成。真实账号返回体与在线执行仍待验证。
