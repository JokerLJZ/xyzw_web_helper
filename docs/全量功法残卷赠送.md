# 全量功法残卷赠送

入口为批量任务「功法」下的「全量功法残卷赠送」，也可加入定时任务。接收者 ID 和安全密码来自已有全局配置。每个账号独立查询赛季状态、任务进度、VIP 和库存。

## 客户端依据

2026-11-26 核对本地 `public/game/index.html`、`game-defines.a175e.js` 和 `main.2a00e.js`。官方清单使用 `platform=hortor&version=0.36.0-android` POST，沿启动器的远程资源转换及 XXTEA 解密路径取得 `game=57a46`、`launcher=3af4e`、`TEST_REMOTE_MODULE=757be`。配置包索引为 `2938b`，数据版本为 `152261a3c8`。已从该版本 JSON 加载并核对赠送相关配置表。

| 客户端位置 | 行为 |
| --- | --- |
| LegacyGiftTaskData 和赠送任务界面 | 每种任务按配置顺序开放，赛季任务类型为 3，使用 `giftTask` 进度和 `giftTaskClaim` 领取记录，达标后调用 `LegacyService.claimGiftTask({id})` |
| LegacyService 注册表与命令枚举 | 领取额度命令为 `legacy_claimgifttask`，响应为 `legacy_claimgifttaskresp`，声明含 `roleLegacy` |
| 功法邮件数据与赠送界面 | VIP 基础额度加已领取的赛季任务加成，减 `sendItemCnt`。按本赛季充值档位判断赠送特权。单次上限同时受库存与 `giftDustMaxAmountOnce` 限制 |
| LegacyModule.sendSendGift 与命令枚举 | 使用 `legacy_sendgift {targetId,itemCnt,legacyUIds:[]}`，响应为 `legacy_sendgiftresp`。当前配置残卷 ID 为 37007，单次上限 9999 |

每次领取额度后用 `legacy_getinfo` 确认，按现有接收者查询及安全密码验证流程完成授权。可赠送量超过单次上限时分批赠送，每批刷新库存；还有下一批时刷新赛季剩余额度。赠送请求异常后结束当前账号，超时时只补查库存。含该任务的定时组关闭失败自动补跑。接收方能否接收由服务端确认。
