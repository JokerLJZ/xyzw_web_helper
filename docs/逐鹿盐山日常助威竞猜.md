# 逐鹿盐山日常助威与竞猜

核对日期：2026-10-12。新增日常选项“逐鹿盐山助威与竞猜”，默认关闭。单账号日常、批量日常及任务模板均可设置；定时日常沿用对应账号或模板设置。

## 执行规则

- 北京时间周一：查询账号助威道具，按游戏当前可助威列表选择第一支未淘汰队伍，将本次开始时持有的全部助威道具用完。单次最多9999个，超过时分批发送，每批后重新查询库存和个人助威次数确认。完成后领取竞技大厅所有已达成、未领取的任务奖励。没有道具或没有可助威队伍时记录跳过，并检查大厅可领取任务。
- 北京时间周日：领取竞技大厅已达成、未领取的任务奖励。
- 每天运行日常时：按服务器当前配置检查所有进行中期次的竞猜阶段。开放时先完整读取可预测对阵，再逐组选择支持人数较多的队伍，平票选列表第一方。已经预测过任意一方的对阵保持原选择，不对另一方重复预测。
- 同一账号每天成功检查一次；再次运行日常直接跳过，不再次发请求。同周周一已完成助威后，再次运行也不消耗新获得的道具。记录存储在本浏览器，换浏览器或清除存储不会共享此频次记录；已有竞猜和领奖仍依据服务器记录跳过。
- 这是一项日常任务步骤，需要开启选项并运行日常；未另建独立后台定时器。非周一、周日仍执行当天竞猜检查，但不执行助威或大厅领奖。

## 时间、限速与异常

复用已定位的Apex赛程规则，新增独立规则实例以读取当前配置。新日常规则固定北京时间，既有页面与批量竞猜保留默认规则入口。竞猜开放为Unlocked或Locked（阵容锁定后、开赛前仍可预测）；Fighting、Completed不可预测；决赛已出现胜利方时停止预测。名额使用当前advanceNum，季军赛按客户端为1。

请求使用既有APEX串行自适应限流器。只读请求有限重试；助威、竞猜、领奖不在限流器中自动重发。写操作前保存待确认记录，失败或超时后先查询是否实际生效。已生效则继续，未确认则停止；中断后重新运行先查询，再依据服务器剩余库存、竞猜和领奖记录继续。跨周或赛季导致旧写入无法可靠核对时停止并提示检查游戏状态。

每日成功检查记录、周一助威记录、待确认写操作均按账号隔离；每次读写前检查用户停止和北京时间日期边界。日常任务复用现有连接与连接池，不自行关闭连接。
