# 逐鹿盐山日常助威与竞猜

核对日期：2026-10-12。新增日常选项“逐鹿盐山助威与竞猜”，默认关闭。单账号日常、批量日常及任务模板均可设置；定时日常沿用对应账号或模板设置。

## 执行规则

- 北京时间周一：查询账号助威道具，按游戏当前可助威列表选择第一支未淘汰队伍，将本次开始时持有的全部助威道具用完。单次最多9999个，超过时分批发送，每批后重新查询库存和个人助威次数确认。完成后领取竞技大厅所有已达成、未领取的任务奖励。没有道具或没有可助威队伍时记录跳过，并检查大厅可领取任务。
- 北京时间周日：领取竞技大厅已达成、未领取的任务奖励。
- 每天运行日常时：按服务器当前配置检查所有进行中期次的竞猜阶段。开放时先完整读取可预测对阵，再逐组选择支持人数较多的队伍，平票选列表第一方。已经预测过任意一方的对阵保持原选择，不对另一方重复预测。
- 每次日常与批量竞猜均检查历史竞猜奖励：只领取已预测的获胜队伍、服务端奖励清单中未领取的奖励。没有开放竞猜阶段或赛季已结束时也检查历史奖励；每笔领取后查询确认，失败或超时不盲目重发。
- 同一账号每天成功预测检查一次；当天再次运行日常跳过重复预测，但仍查询并领取随后出现的竞猜奖励。同周周一已完成助威后，再次运行也不消耗新获得的道具。记录存储在本浏览器，换浏览器或清除存储不会共享此频次记录；已有竞猜和领奖仍依据服务器记录跳过。
- 这是一项日常任务步骤，需要开启选项并运行日常；未另建独立后台定时器。非周一、周日仍执行当天竞猜检查，但不执行助威或大厅领奖。
