## 条件

RFHonorData.bookId 从 ROLE.getStatisticValue("pk:appoint:room:id",true) 读取。bookStatus 比较当前 roomId：相同正数为已关注，相同负数为已领取，其他为未关注。不是按每日清零；每次任务读取本账号当前场次。
RFHonorData.officialMatchStatus：roomId 为空或 type 非 official（协议枚举0）则无比赛；firstMatchTime>0 且服务器时间严格大于 firstMatchTime*1000 时，详情 state 为 close（枚举5）则关闭，否则进行中；其余等待。
大厅 _refreshBookBtn：等待阶段允许关注；进行中仅已关注者可领取；已领取、未提前关注、关闭或非正式场次均不写请求。无需加入比赛房间或报名，也无 roomId 写参数。
