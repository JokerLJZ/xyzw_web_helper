# 皮鞋配置版本不一致研究方案

日期：2026-11-24。仅公开资源只读调查，未修改项目代码、未连接账号或执行道具操作。

## 已验证

本地public/game入口及main的manifest、URL转换、XXTEA解密规则用于重新下载当前launcher/game。manifest参数platform=hortor、version=0.36.0-android；game=57a46、launcher=3af4e、config=2938b、dataBundleVer=152261a3c8。

launcher的版本处理会在非dev且不使用打包配置时将bundleVersions.config替换为dataBundleVer；ResourceManager.loadWebConfig默认加载8个JSON，开发分支加载bundle的JsonAsset；二进制分支使用BON解码。不能把原清单config哈希下的configc自动视为账号同版本数据。

只读实测：原config.2938b.json索引下configc内部COMMIT_ID=a5582ce672；config.152261a3c8.json可访问，但其configc内部COMMIT_ID=36df019506，仍不匹配。版本路径JSON合并结果COMMIT_ID=152261a3c8但缺WeaponConf和WeaponPassiveConf。主CDN的8类JSON直链均404，备用CDN的config.json/configc.bin直链也404。

当前项目shoeToyRunner依赖WeaponConf、WeaponActiveConf、WeaponPassiveConf，费用和上限不能由缺表的JSON推断。上述证据不能证明不同内部版本代表兼容版本，也不能断言资源一定是旧版；先前“旧配置”的描述过强。

## 推荐后续方案

第一阶段：只读检查用户正常打开的当前游戏，追踪已加载配置的实际来源和覆盖顺序，提取皮鞋相关三张表及当前账号配置版本；优先通过正式运行时配置对象或真实资源响应取得，不执行升级、解锁、领取或换阵。若运行态也无可靠版本来源，停止而不伪造版本。

第二阶段：确认来源后实施专用皮鞋配置适配，不全局放宽officialTaskConfig。配置包含账号版本、实际来源和内容摘要，校验皮鞋ID、费用、等级上限、被动门槛和关联表引用；缓存按账号配置版本与来源摘要隔离。没有可核实配置时继续停止。

第三阶段：用真实配置离线验证现有任务判断，覆盖库存不足、等级上限、星级门槛、版本改变和不完整配置；运行相关测试及构建。先交付只读预览（当前状态、预计步骤、费用），实际执行任务仍单独确认。

## 备选与边界

若无法取得当前运行态配置，可等待官方发布可验证资源并改善任务提示/重复失败日志。直接取消COMMIT_ID校验或硬编码旧费用不建议采用。不同版本的三张玩具表即使一致，也只能证明这些快照内容一致，不能单凭此证明与账号当前规则相同。

本次只验证资源可用性与加载器静态行为，尚未取得真实运行态配置与皮鞋操作响应。未运行项目测试或构建，因为本次没有实施代码修改。

## 2026-11-25 运行态确认及修复

通过Edge已打开的同源游戏iframe只读检查，确认__require('PlatformManager').PlatformManager.instance.platformType为hortor，GAME_VERSION为1.89.8-wx，RemoteConfigs.remoteDataVer为152261a3c8。未调用账号服务或执行升级。运行态WeaponConf.getById(2)存在，maxLevel=150、passiveLimit=10。performance资源记录明确加载remote/config/config.152261a3c8.json及8份import JsonAsset。

重新按该索引下载全部JsonAsset后，发现此前调查遗漏：WeaponActiveConf/WeaponPassiveConf在level资源，WeaponConf在language资源。language不是只有翻译文本；仅合并config与config_ap会造成玩具表缺失。原先“JSON无法替代”的结论不成立。无需绕过二进制版本校验，也无需先修改账号版本查询参数。

实现：officialTaskConfig新增皮鞋专用toy选项，按已核对账号版本加载config.<version>.json，合并config、config_ap、level、language；主配置必须COMMIT_ID一致，其他资源声明COMMIT_ID时也严格校验。toy与其他模式缓存分开。皮鞋入口改用该模式，其余业务不变。不硬编码本次版本、费用或CDN资产哈希。

真实公开资源按新加载器合并并通过validateShoeToyConfig，版本152261a3c8，皮鞋上限150；未升级或消耗道具。测试覆盖分表加载、禁用二进制路径、分表版本不一致拒绝。大型分析资源仍在/tmp，不加入游戏目录。
